# 去中心化分布式跨平台自进化 AI 学习系统

> **当前状态：资料收集完成 · 架构框架已定稿至 v2**（2026-11-02）
> 本仓库目前**只有文档，没有代码**。下一步是按框架 v2 的阶段 ①「能装内容」立项。

---

## 这个项目想做什么

一句话：**不是训练一个更大的模型，而是做一个「会记账的自进化学习系统」**——把每一次人的学习与 AI 的工作都变成带证据的经验，跨设备同步经验与轻量适配，并以可审计的曲线证明它真的在变强。

### 为什么是这个定位

调研（见 [`docs/资料/00-索引与阅读指南.md`](docs/资料/00-索引与阅读指南.md)）得出三条关键判断：

1. **赛道四块拼图（去中心化训练 / 智能体自进化 / 跨平台多设备 / 学习闭环）都已各自成熟，但没人缝成整体。** 唯一认真缝合的开源项目 Continuum 自己承认，其核心命题（经验能否带来长期能力提升）**仍是未解的科研问题**。
2. **「自进化」的有力证据全在「不碰权重」的层。** 严格复现且有公开数字的成果集中在 prompt / 记忆 / 技能库 / 代码工作流 + 外部评估器；改权重那层连作者自己都只定义为 "a promising step"。**所以进化押在技能层，不押在训练层。**
3. **最大的差异化是「人机互学 + 可验证的进步」。** 学界已证明 LLM 能「边教边学」（LbT，NeurIPS 2024，免训练仅提示即可把 GPT-4o 在 MATH 上 87.84% → 96.69%），但**没人把它工程化到个人设备 + 跨设备 + 可审计账本**。

## 三条最重要的设计约束（调研结论）

| 约束 | 事实 | 后果 |
|---|---|---|
| **移动端不能后台常驻**（平台事实，非架构分级） | Android 15+ 前台服务 24 小时内合计仅 6h；iOS `BGProcessingTask` 约 60 秒 | 手机仍是**完整节点**（框架 A1），只是同步发生在「打开 App 时」而非后台 |
| **约 30% 连接必须走中继** | DCUtR 实测 440 万次打洞，成功率 70%±7.1%（非厂商自述的 90%） | 必须自托管中继池，这是一级成本项 |
| **变更必须先于宣称** | 全行业都缺「本周比上周强了多少」的可审计账本 | 证据账本（框架 §8 / 资料 06）必须先于任何效果宣称 |
