# 集合的概念与运算

## 直观理解
集合就是「一袋确定的东西」。袋子里的每样东西叫元素。**确定性**是关键：说「高个子的人」不构成集合（多高算高？），说「身高超过 180cm 的人」就是集合。

三种基本运算：
- **交集 A∩B**：两个袋子**都**有的东西（重叠部分）
- **并集 A∪B**：两个袋子合起来（去重）
- **补集**：全集里挖掉这个袋子剩下的

## 规范表述
集合中元素具有**确定性、互异性、无序性**。
A∩B = { x | x∈A 且 x∈B }；A∪B = { x | x∈A 或 x∈B }。

## 常见误解
- 把交集当成并集（最常见）；
- 忽略元素互异性，写 {1,1,2}；
- 认为 {1,2} 与 {2,1} 是不同集合（无序性）。
