# 同步指南

WORDO 的同步方式很简单：**把「账号域目录」放到一个被同步的磁盘位置即可**。各设备指向同一个目录（或同一个被同步的目录），同步由系统的文件同步工具完成——应用本身不发明同步协议。

---

## 一、为什么不需要 merge 算法

「无冲突」不是靠合并算法，而是靠**数据结构的形状**：

- **每个节点只追加自己的文件**：`ledger/<node>.jsonl`、`chats/<id>/<node>.jsonl` 的文件名带节点标识，各设备各写各的，永不同名。
- **共享的都是派生视图**：`user.md` / 学习计划由账本在内存重算（`derive` 幂等），**不落共享盘**，所以不存在「两端各写一份视图」的冲突。
- **删除 / 重命名是事件**：写 `__deleted` 墓碑 / `__rename` 事件，旧副本不会让内容「复活」，历史仍可审计。
- **seq 单调 + 重复 id 检测**：`verify_ledger` 能自检「是否丢了事件、是否被重放」。

结果：同步工具只需做「文件搬运」，**碰撞面天然极小**。双节点并发写 240 条实测 0 重复 / 0 缺口 / derive 幂等。

---

## 二、三种同步通道与选择建议

| 通道 | 适合场景 | 优点 | 注意 |
|---|---|---|---|
| **OneDrive / 云盘** | 偶尔多设备、跨网络 | 装好即用、自动跨网 | 多设备同时在线时云盘可能生成「冲突副本」；对 append-only 分文件写入影响很小，但建议错峰 |
| **Syncthing（P2P）** | 经常多设备、想数据自持、彻底去中心 | 无中心服务器、可选择性忽略文件（如排除 `node.json`）、与项目去中心气质一致 | 需在每台设备装并配好共享设备/文件夹；首次配对略麻烦 |
| **局域网共享（SMB / 网络驱动器）** | 家里 / 教室里多设备、同一网络 | 简单、低延迟 | 跨网络不可用；需保证每台设备稳定挂载同一目录 |

**怎么选：**
- 只想「省事、能用就行」→ **OneDrive / 云盘**。
- 想「数据自己掌握、完全去中心、能精细排除文件」→ **Syncthing（最契合本项目理念）**。
- 同屋多设备、追求简单快速 → **局域网共享**。

三者可以混用（例如家里局域网共享 + 出门用 Syncthing），只要**指向的是同一批被同步的文件**即可。

## 三、node.json：节点身份

- 每台设备在**首次访问账号域时自动生成**自己的 `node.json`，节点 id 由主机名（`COMPUTERNAME` / `HOSTNAME`）派生，形如 `pc-a1b2`。
- 节点 id 决定账本文件名（`ledger/<node>.jsonl`）。**每台设备必须保持自己的 node id 唯一**。
- ⚠️ 实践注意：`node.json` 位于账号域根目录。如果多台设备共用「同一个被同步的目录」，请让每台设备保留**各自的** `node.json`（推荐在同步工具里**排除 `node.json`**，让它只存在本机），避免所有设备读成同一个节点 id 而造成账本混写。
  - 若此前已经串号，删除本机 `node.json` 让它按当前主机名重新生成即可（历史账本按旧 node 归档，仍可审计）。

## 四、多设备如何配对同一个域

1. **准备一个被同步的位置**：选定 OneDrive / Syncthing / 局域网共享中的一种，建好账号域目录（可直接把现有 `%APPDATA%\app.wordo.desktop\domain\default` 迁进去）。
2. **每台设备指向它**：设置环境变量 `WORDO_DOMAIN=<该目录>`（或把默认账号域路径指向它）。CLI 与 GUI 都会读这个路径；命令行也可用 `--domain` 显式指定。
3. **首次访问生成各自身份**：每台设备第一次读写时自动写自己的 `node.json`（见上一节，建议同步时排除该文件）。
4. **确认合并正确**：在任意设备跑一次账本自检（`wordo verify_ledger` 或 API `verify_ledger`），应报告无重复 id、无 seq 缺口、无未知知识点引用。
5. **之后照常使用**：各设备新增的事件写在各自账本文件里，同步工具把文件搬过去，下次打开就是合并后的视图。

> 密钥 / 模型配置**不在账号域**：它在应用配置目录 `%APPDATA%\app.wordo.desktop\config.json`，每台设备各自配置。不要为了「同步方便」把 `config.json` 放进账号域（见下节）。

---

## 五、安全与注意

- **不要把密钥写进账号域目录**。账号域会被同步到云端或其他设备；API Key 只应留在本机应用配置里（`config.json` / 环境变量）。
- **账号域目前是明文**（多账号、密钥托管、域加密尚未做）。敏感环境请自行决定是否使用加密同步盘，或在支持加密的通道上同步。
- **不要手动编辑账本 JSONL**：它带单调 `seq`，手改易造成缺口。要纠正学习状态，应通过正常作答/事件追加完成。
- **同步工具处理二进制无需特殊设置**：账号域全部是文本文件（JSONL / MD / JSON），普通文件同步即可。
