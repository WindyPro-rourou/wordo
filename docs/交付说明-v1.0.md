# WORDO 交付说明 v1.0（2026-11-07）

> 一句话：**一台设备就能跑完整学习环路；多设备靠「append-only 账本 + 派生视图」同步，结构上不冲突；界面是 chat-first，学科由第一句话自动判定。**

## 一、现在能做什么（可点可验）

| 能力 | 入口 | 状态 |
|---|---|---|
| 对话式学习（讲解 / 出题 / 判分 / 复习建议） | 对话页输入框；「讲讲一般过去时」「给我出两道题」「我该复习什么」「混合练 3 个薄弱点」 | ✅ 真调模型，11–15s，首轮过 schema 校验 |
| 学科自动判定 + 手动纠错 | 顶栏学科胶囊 / 手机底部抽屉 | ✅ 命中知识点名 5 分 > 学科名 3 > id 2 > 简称 1；纠错写事件不改历史 |
| 会话历史 | 侧栏（桌面）/ 抽屉（手机） | ✅ 新建 / 切换 / 删除（墓碑）/ 自动标题 |
| 今日任务 | 今日页 | ✅ 复习队列 → 薄弱 → 学习计划 → user.md |
| 答题记账（含讲解内检测题） | 任意检测题 | ✅ 落账（合成 id + 来源标记），带 **置信度三档** 与 **错因分型** |
| 间隔复习 | 自动 | ✅ 错→4h / 不确定对→×1.4 / 确定对→×2（上限30天）；**蒙对按错处理**；已掌握→≥14天抽查 |
| 跨设备错题委托 | 今日页「导出今日错题」/「处理域内委托」 | ✅ 文件文书 + 回执，账号域内任一设备可处理 |
| 周报 | 今日页「导出周报」 | ✅ 写入 `reports/周报-YYYY-MM-DD.md` |
| 教师视图（题库/知识树/校验报告） | 设置页 → 教师视图 | ✅（是否对学生隐藏待定） |
| 账本自检 | `verify_ledger`（API/CLI） | ✅ 重复 id / seq 缺口 / 未知知识引用 |

## 二、怎么跑

**开发期（本机无 Rust 也可）**
```powershell
cd tools/preview
npm i            # 仅需 playwright-core（用系统 Edge）
node seed.mjs    # 造演示账号域
node server.mjs --port 4310
# 浏览器打开 http://127.0.0.1:4310
```
自迭代/验收脚本：`shoot.mjs`（6 视口巡检）· `ai-test.mjs`（端到端模型）· `interact.mjs`（交互回归）
`test-p1p2.mjs`（落账/会话事件化）· `test-concurrency.mjs`（双节点并发）· `test-sci.mjs`（学习科学）· `test-rules.mjs`（SRS 规则）

**正式构建（需 Rust + MSVC）**
```powershell
cd core; cargo build                 # CLI: wordo
cd apps/desktop/src-tauri; cargo build   # 桌面壳
cargo test --lib                     # 契约测试
```

## 三、数据模型（可迁移、可审计）

```
<账号域>/
  node.json                 本机节点身份
  ledger/<node>.jsonl       每节点 append-only 账本（含单调 seq）
  user.md                  派生（不写共享盘；每次按账本重算）
  chats/<id>/<node>.jsonl   会话事件（消息/重命名/墓碑），读时合并
  wrong/<date>-<node>.md     错题委托（人读+机读）
  reports/周报-YYYY-MM-DD.md
  settings.md / plan.md     settings 为设置源；plan 已降级为派生物
```
无冲突原理：**每节点只追加自己的文件**；视图（user.md/计划/会话）都是合并派生。删除写墓碑、id 带节点后缀、seq 单调 → 可检测丢失与重放。

## 五、已知限制（诚实清单）

1. **Rust 侧未编译**：本机无 Rust 工具链；所有 Rust 改动需在有 cargo+MSVC 的机器上 `cargo build && cargo test --lib` 验证一次。
2. **模型网关**：`auto/*` 是路由组，跨调用可能落到不同上游 → 一致性测量有波动；正式测量应固定具体上游 id 并控制频率（密集调用已出现 502/超时）。
3. **内容规模是 demo 级**：两个学科包各 5 个知识点、3 道题。真实使用前需要「每个知识点 5–10 道经典题」的前置内容建设（见待决策 A1/A2）。
4. **账号域未加密**：目前是明文目录 + 同步盘；多账号、密钥托管未做。
5. **教师视图定位未定**：评审建议改为「导出周报给老师」，而非让老师登录看板。
