## 三、未验证项（诚实声明）

1. **桌面运行时（WebView2）未在本机实机复测**：Rust 由 CI 编译+单测、界面逻辑由 Chromium 无头验证；真实 Tauri 窗口行为需在 Windows 上首次运行确认。
2. **Android / iPadOS 未实机构建**：给出构建步骤（`apps/mobile/README.md`、`docs/多端构建指南.md`），需 Android SDK/NDK + JDK17 / macOS+Xcode。
3. **ESP32 固件未上机**：`embed/esp32-node/main.cpp` 为参考草图；主机侧协议桥 `tools/mininode` 已自测。设备时钟建议接 RTC/SNTP。
4. **网关不稳**：多模型评审中 `kimi-k3.1-pro` 多数超时、`glm` 偶发超时（属网关侧），不影响仓库。
5. **内容仍为 demo 级**：真实可用需按「每知识点 5–10 题」补齐（内容由用户自备，`tools/ingest` 负责入库）。

## 四、待决策项（沿用路线图 A–E，并新增两点）

- A 内容来源（模型批量草稿+校验 vs 你提供题库；是否需要「粘贴文本→抽题」零档向导）
- B 平台优先级（iPadOS / ESP32 / 教学工具层）
- C 许可（框架 PolyForm NC；学科包内容 CC BY-SA 4.0 待定稿）
- D 同步通道（OneDrive / Syncthing / 局域网；域加密与多账号是否现在做；API Key 是否随域同步——建议**不**）
- E 教师视图（保留 / 导出周报 / 对学生隐藏）
- **F（新）同步时是否排除 `node.json`**：账号域若整体同步包含 `node.json`，多台设备会共用同一节点 id，破坏「每节点只追加自己账本」。建议同步工具排除 `node.json`（或后续把节点身份移出同步目录）。**当前按文档建议排除，未在真机多设备验证。**
- **G（新）新学科是否默认内置示例内容**：当前默认内置「示例知识点（可删）」以让新学科立即可用；若你希望纯空骨架，可加开关。
