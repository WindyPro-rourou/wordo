## ① 一句话结论

**本项目的「学习」必须定义为「双向共生」——人的学习是需求侧与价值锚点，AI 的学习是供给侧与实现手段，二者共享同一套记忆与调度机制；只做其中一侧都会让项目失去立项理由。**

三条论据：

1. **「帮助人学习」这一侧的科学基础是整个赛道里唯一的硬资产**。记忆与遗忘的规律（间隔效应、检索练习、交错练习）、掌握学习、知识追踪、自适应测试，都有几十年可复现的实证支撑，且已被工业级算法（FSRS、BKT/DKT、Elo-CAT）工程化。相比之下「AI 自我进化」目前**没有公认的收益证据**。
2. **「AI 自我学习」这一侧尚无可靠证据，且已有反例**。文档 06 已记录：自我改进策略可能收敛到「骗过裁判但不可检测的对抗解」；而 AI 教育产品的实证效应远低于宣传——Khanmigo 经 WestEd 一学期 RCT 仅得 **0.15 个标准差**（47 所学校，二手转述，原始报告待核实，见 ⑥）。
3. **两侧在算法层面同构，做一份工程得两份收益**。间隔重复的 `S/D/R` 状态、Zettelkasten 的「原子化笔记 + 动态链接」、时序知识图谱、检索练习与主动回忆，在人类记忆与智能体记忆里是**同一组数学对象**——A-MEM 直接声明自己照搬 Zettelkasten 原则（<https://arxiv.org/abs/2502.12110>），MemoryBank 直接用艾宾浩斯遗忘曲线做衰减（<https://ar5iv.labs.arxiv.org/html/2305.10250>）。

**可操作结论**：产品对外定位是「帮人学得更牢、更快、更久」，对内架构是「一套可自进化的记忆体」。二者用同一套 `记忆条目 + 强度 + 复习调度 + 知识图谱` 数据结构表达。**不要**对外宣称「自进化 AI」，除非能拿出文档 06 的三层账本。

**读图要点（三条轴线）**

- **纵轴是「时间」**：左侧一切都在描述「记忆随时间怎么衰减、怎么被复习救回来」；右侧一切都在描述「能力随练习怎么增长」。
- **横轴是「信念的对象」**：左边建模「一个人的记忆」，中间建模「一个人的知识状态」，右边建模「一个智能体的上下文」。
- **本项目的机会点**：把纵轴的 `S/D/R`（记忆强度/难度/可提取度）做成**跨人或跨智能体可迁移的通用状态**——这是「去中心化 + 分布式」在算法上唯一说得通的落点（不同节点各持一份记忆体，用同一套状态交换与同步）。

## ⑤ 可落地的算法清单

以下 6 条按「可直接写代码」标准给出。全部标注了来源，实现细节属工程自由裁量。

### 5.1 FSRS 复习间隔（首选，工程最成熟）

FSRS 的记忆状态是三元组：`S`（稳定性，天）、`D`（难度，1–10）、`R`（可提取度，0–1）。

**可提取度（遗忘曲线）**——FSRS-5：

```
R(t, S) = (1 + t / (9 * S)) ^ (-1)
```

FSRS-6 把衰减指数变成可训练参数 `w20`，并引入可训练的 `factor`：

```
R(t, S) = (1 + factor * t / S) ^ (-w20)
```

**难度更新与均值回归**（避免「ease hell」）：

```
D' = D - w6 * (G - 3)
D_new = w7 * D0(3) + (1 - w7) * D'      # 向「容易」的均值回归
```

**成功复习后的稳定性增长**：增量为 `SInc = S'_r(D,S,R,G) / S`，满足三条性质——难度越大增量越小、S 越大增量越小、**R 越小增量越大（这就是间隔效应被数学化）**。

**遗忘后的稳定性**：

```
S'_f(D,S,R) = w11 * D^(-w12) * ((S+1)^(w13) - 1) * e^(w14 * (1-R))
例（默认参数）：D=2, R=0.9 时，S'_f(S=100) ≈ 3，S'_f(S=1) ≈ 0.3
```

**间隔计算（业务层伪代码）**：

```python
def next_interval(S, desired_retention=0.9, max_ivl=36500):
    # 反解 R(t,S) = desired_retention 得到 t
    factor = 19/81 if FSRS5 else learnable_factor   # FSRS-5 的等价形式
    ivl = (S / factor) * (desired_retention ** (-1/decay) - 1)
    return clamp(round(ivl), 1, max_ivl)
```

**来源**：<https://github.com/open-spaced-repetition/fsrs4anki/wiki/The-Algorithm>（公式与「S'_f 数值示例」均引自该页）；开源实现 <https://github.com/open-spaced-repetition/py-fsrs>；Anki 自 **23.10** 版本起引入 FSRS <https://docs.ankiweb.net/releases/changes/changes/23.10>。

**工程提示**：FSRS 的 21 个参数（FSRS-6）需要用**用户自己的复习日志**拟合；冷启动阶段直接用官方默认参数，不建议自行调参。

### 5.2 IRT 能力估计（2PL）

单题正确概率：

```
P(X=1 | θ, a, b) = 1 / (1 + exp(-a * (θ - b)))          # 2PL
P(X=1 | θ, a, b, c) = c + (1-c) / (1 + exp(-a*(θ-b)))   # 3PL，c 为猜测率
```

**能力估计（在线 Elo 式，Math Garden 风格）**：

```
期望正确率  E = 1 / (1 + exp(-(θ - b)))       # 也可用带 a 的 2PL 形式
θ ← θ + K * (y - E)                            # y = 1 答对 / 0 答错
b ← b - K * (y - E)                            # 题目难度反向更新
```

**选题策略（CAT）**：在题目池中选 `|P(正确) - 0.5|` 最小（信息量最大）者；若追求 ZPD，则选 `P(正确) ≈ 0.6–0.8`。

**来源**：2PL/3PL 定义 <https://scholarworks.uark.edu/cgi/viewcontent.cgi?params=/context/etd/article/4751/&path_info=Morrison_uark_0011A_13418.pdf>；Elo 式在线更新与 Math Garden 实现 <https://cran.r-project.org/web/packages/meow/vignettes/maths-garden-update.Rmd>、<https://dl.acm.org/doi/10.1016/J.COMPEDU.2011.02.003>。

### 5.3 BKT 四参数更新（最可解释，冷启动友好）

四个参数：`P(L0)` 初始掌握、`P(T)` 学习率、`P(G)` 猜测、`P(S)` 失误。

```
# 预测（答题前）
P(L_t) = P(L_{t-1}) + (1 - P(L_{t-1})) * P(T)

# 观测到答对 y=1
P(L_t | correct) = P(L_t)(1-P(S)) / [ P(L_t)(1-P(S)) + (1-P(L_t))P(G) ]
# 观测到答错 y=0
P(L_t | wrong)   = P(L_t)P(S)     / [ P(L_t)P(S)     + (1-P(L_t))(1-P(G)) ]
```

**来源**：Corbett & Anderson (1995) 转述 <https://d-nb.info/102380946X/34>。

### 5.4 DKT 输入 / 输出（序列建模）

```
输入 : x_t = [ (q_t, r_t) ]_{t=1..T}    # q_t = 题目/知识点 one-hot 或嵌入；r_t ∈ {0,1} 是否正确
隐藏 : h_t = LSTM / GRU / SelfAttention(x_t, h_{t-1})
输出 : y_t = σ(W h_t + b) ∈ [0,1]       # 预测「下一题答对」的概率
损失 : L = -Σ_t [ r_{t+1} log y_t + (1 - r_{t+1}) log(1 - y_t) ]
```

**关键点**：DKT 的输入是**「题 + 答」的拼接序列**，输出是对**下一题**的预测。这个「预测未来的对错」就是可迁移到「预测用户何时遗忘」的同一形式——只是把「题」换成「记忆条目」。

**来源**：<https://arxiv.org/abs/1506.05908>；后续 SAKT/SAINT/AKT 见 ③ 3.2 表。

### 5.5 先修图 + ZPD 选题

```python
def pick_next(learner, skill_graph, mastery):
    # 1) 先修达标过滤：所有先修知识点掌握度 >= phi_prereq (≈0.50)
    ready = [s for s in skill_graph.nodes
             if all(mastery[p] >= 0.50 for p in skill_graph.predecessors(s))]
    # 2) ZPD 过滤：当前掌握度落在 [phi_prereq, theta_ready] (≈0.50, 0.80)
    zpd = [s for s in ready if 0.50 <= mastery[s] <= 0.80]
    if not zpd:
        zpd = ready or [弱项排序首项]
    # 3) 记忆调度：在 ZPD 内按 FSRS 到期紧急度排序
    return max(zpd, key=lambda s: due_pressure(s))
```

**来源**：ZPD 阈值工程实践 <https://www.sciencedirect.com/science/article/pii/S259000562600278X/pdfft>、<https://www.npmjs.com/package/learngraph>；先修关系建模 <https://openresearch-repository.anu.edu.au/bitstreams/8f64a201-3095-4509-83d6-a1ed0179b9b6/download>。

### 5.6 智能体记忆：写入 / 检索 / 遗忘

**检索打分**（Generative Agents 风格）：

```
score(m) = α * recency(m) + β * importance(m) + γ * relevance(m)

recency(m)  = decay ^ (now - last_access(m))      # decay 常取 0.99/小时量级
importance(m) = LLM 打分 1–10
relevance(m)  = cos(embed(query), embed(m))
```

**遗忘 / 淘汰**（MemoryBank 风格，直接借艾宾浩斯）：

```
R(m, t) = exp(-t / S(m))          # 可提取度随时间衰减
S(m) ← S(m) * (1 + η)  当 m 被成功检索（复习）
若 R(m, t) < τ 则归档或删除
```

**整合 / 巩固**（Zep / Graphiti 风格 + 睡眠类比）：

1. 新记忆写入时抽取 `(实体, 关系, 时间)` 三元组，写入**双时态**时序知识图谱；
2. 冲突时**不覆盖**，而是标记旧边失效并保留历史（timeline）；
3. 离线期（"sleep-time"）做**合并、抽象、去重**——等价于人类睡眠期的经验回放。

**来源**：<https://dl.acm.org/doi/fullHtml/10.1145/3586183.3606763>（记忆流打分）；<https://ar5iv.labs.arxiv.org/html/2305.10250>（遗忘曲线）；<https://arxiv.org/abs/2501.13956>（时序 KG）；<https://arxiv.org/abs/2502.12110>（Zettelkasten 式动态建链与记忆演化）；<https://www.letta.com/blog/sleep-time-compute>（离线巩固）；神经科学对照 <https://www.sciencedirect.com/science/article/abs/pii/S0149763421003444>。

## ⑥ 坑与风险

### 6.1 教育 AI 的实证效力被系统性夸大

- **2σ 是被误用的数字**。Bloom 1984 的结论是「一对一辅导」可带来约 +2σ，**从未主张任何技术手段能达到**。行业把「2σ」当作品牌的现状已被公开批评 <https://liveinthefuture.org/stories/ai-education-desirable-difficulty-memorization>。
- **RCT 结果远低于宣传**：Khanmigo 一学期 47 校 RCT → **0.15σ**（二手转述，**原始报告待核实**，<https://k12flash.com/what-one-year-of-real-classroom-data-reveals-about-ai-tutoring-the-honest-truth-about-khanmigo/>）。
- **元分析结果高度异质**：AI 支持 SRL 的 35 项研究元分析得 `g = 0.507`（中等，<https://www.fachportal-paedagogik.de/literatur/vollanzeige.html?FId=eric_ej1514392>）；另一份 32 项研究 / 92 个效应量的综述报告 `g = 1.613`（<https://public-pages-files-2025.frontiersin.org/journals/education/articles/10.3389/feduc.2025.1738751/text>）。**同一主题相差 3 倍以上，说明测量与实施条件主导了结果**——引用时必须挑明异质性。
- **多数 ITS 研究没有对照组**：npj Science of Learning 的 K-12 系统综述明确指出这一点 <https://www.nature.com/articles/s41539-025-00320-7>。
- **反面证据要正面吸收**：「学习风格匹配」无可靠证据 <https://pubs-acs-org-443.webvpna.lzu.edu.cn/doi/pdf/10.1021/acs.jchemed.7b00424>。**不要把「个性化 = 匹配学习风格」写进产品叙事**，这是一个已被证伪的卖点。

> **对本项目的含义**：任何「我们的 AI 让学生学得更好」的声明，必须自带**对照组 + 延迟测试 + 效应量**，否则就是 ⑥ 6.1 的反面教材。

### 6.2 过度自动化与技能退化

- LLM 直接给答案 → **生成效应/检索练习被绕过**，学习效果反而下降（合意困难理论，<https://hal.science/hal-02422145v1/document>）。
- 自动评分在作文、课堂观察等场景存在**公平性差异**（尤其对 EFL 学习者）<https://doaj.org/article/b354f40c6ef7431395c473df30007061>。
- **过度依赖（overreliance）**已被列为 GenAI 教育四大可靠性风险之一（同上）。

> **设计红线**：AI 的角色是「出题者 + 反馈者 + 调度者」，**不是「答案提供者」**。默认交互应是先让学生尝试，再给脚手架式提示。

### 6.3 幻觉与事实性风险

- LLM 出题/评分存在**幻觉与偏见**，是教育产品集成 LLM 的主要风险 <https://ieeexplore.ieee.org/document/11334308/references>。
- **缓解手段（按性价比排序）**：① 从**已审核题库存量**中检索而非生成；② RAG 锚定到权威教材（<https://arxiv.org/abs/2005.11401>）；③ 多跳/关系型内容用 GraphRAG / LightRAG 而不是纯向量检索（<https://ieeexplore.ieee.org/document/11477693>）；④ 生成内容入池前**必须人工或规则审核**。

### 6.4 数据隐私与未成年人保护（**本项目风险最高的合规项**）

|---|---|---|

| 欧盟 **GDPR** | 默认 16 岁，成员国可降至 13 岁；需监护人同意；含被遗忘权 | 「去中心化存储」与「被遗忘权」存在张力 |
| 中国 **PIPL** | 不满 14 周岁未成年人个人信息需监护人同意，且需专门处理规则 | 官方全文 <https://www.spp.gov.cn/spp/fl/202108/t20210820_527244.shtml>（**具体条文号待核实**） |

> ⚠️ **与「去中心化」的结构性冲突**：分布式/P2P 存储意味着数据被复制到多个节点，而 GDPR 的被遗忘权、FERPA 的披露控制、PIPL 的单独同意都要求**可集中撤回**。这是本项目必须在架构层解决、而非在合规文档里绕开的问题（详见文档 07）。

### 6.5 算法与工程坑

- **数据集不可比**：同一数据集在不同论文里规模不同（见 ④ 表注），跨论文比数字是常见错误。
- **KT 模型的伦理风险**：跨架构审计发现深度知识追踪存在**人口统计偏见**（AKT 的 Rasch 嵌入同时带来约 4 个 AUC 点的提升与最大的社会经济 ABROCA）<https://export.arxiv.org/pdf/2609.20249>。
- **冷启动**：FSRS 需复习历史、DKT 需序列数据、IRT 需题目标定。**冷启动阶段只能用默认参数 + BKT/Elo**。
- **智能体记忆基准不可全信**：Mem0/Zep 的数字均来自各自论文的**自评基准**（LOCOMO / DMR / LongMemEval），词表与评测协议各异，尚无公认第三方横评（`srs-benchmark` 只覆盖间隔重复，不覆盖智能体记忆）。
- **「自进化」的收敛风险**：自我改进可能收敛到对抗性解（见文档 06 引用）。

## ⑦ 对本项目的 5 条可落地建议

### 建议 1：把「双向共生」写进架构，而不是写进宣传

**做法**：定义**唯一的核心数据结构** `MemoryItem`，人类学习与智能体记忆共用：

```
MemoryItem {
  id, content, embedding,
  S: 稳定性, D: 难度, R: 可提取度,       # FSRS 三元组
  last_review, next_due,
  links: [id...],                        # Zettelkasten 式动态链接
  t_valid, t_invalid,                    # 双时态（Zep/Graphiti 式）
  importance: 1-10, source: "human"|"agent"
}
```

同一份引擎同时服务「用户复习调度」和「智能体上下文组装」。**这既是产品差异化，也是工程省钱**——只需维护一套调度器与一套基准测试。

### 建议 2：记忆调度直接采用 FSRS，不要自研

**理由**：FSRS 开源、有基准、有 21 参数可训练模型、Anki 已集成（<https://docs.ankiweb.net/releases/changes/changes/23.10>），而自研间隔算法几乎必然更差。**冷启动用默认参数，积累 1000+ 复习记录后再拟合个人参数**。同时用 `srs-benchmark` 建立回归测试，把「算法换版本后是否变差」变成 CI 的一部分。

### 建议 3：能力建模用「BKT/Elo 冷启动 → DKT/IRT 升级」的双层策略

**理由**：BKT（1995）与 Elo 式在线更新（Math Garden, 2011）在**小数据与冷启动**下可用且可解释；DKT 系（2015–2020）精度更高但需要大量序列数据。**不要一开始就上 Transformer 知识追踪**——本项目早期没有 EdNet 级别的数据量（1.3 亿次交互 / 78 万学生，<https://ar5iv.labs.arxiv.org/html/1912.03072>）。同时**主动记录人口统计偏见的监控指标**（ABROCA），避免复制 ⑥ 6.5 的问题。

### 建议 4：学习路径 = 先修 DAG + ZPD 阈值 + 记忆到期压力，三者并联

**理由**：单纯的知识图谱推荐会忽略遗忘，单纯的间隔重复会忽略先修。用 ⑤ 5.5 的伪代码把三者串成一个打分函数：**先修达标（≥0.50）→ ZPD 窗口（0.50–0.80）→ FSRS 到期紧急度排序**。知识图谱的构建应从**用户自己的笔记与错题**中抽取（借助 LLM 抽取实体-关系），而不是预置一套静态学科图谱——后者维护成本极高且容易与用户实际需求错位。

### 建议 5：把「学习效果验证」做成产品的第一等公民（与文档 06 的 L3 层对齐）

**理由**：这个赛道最大的空位不是功能，而是**没人能证明有效**（文档 06 的核心论断）。本项目应内置：

| 层级 | 必测项 | 频率 | 对应文档 |
|---|---|---|---|
| 即时 | 后测正确率 | 每次会话 | 本文 ⑥ 6.1 |
| 短期 | 24h / 7d 延迟测试 | 每周抽样 | Cepeda 间隔效应 <https://www.psychologicalscience.org/observer/temporal-spacing-and-learning?pdf=true> |
| 长期 | 30d+ 保持率、迁移题正确率 | 每月 | PSI 延迟保持优势 <https://files.eric.ed.gov/fulltext/ED275872.pdf> |
| 对照 | 至少一个**无 AI 辅助对照组** | 每个实验 | npj 综述批评「多数 ITS 无对照组」<https://www.nature.com/articles/s41539-025-00320-7> |

**明确红线**：在没有上述数据之前，对外只能宣称「提供间隔重复与自适应练习」，**不得宣称「提升学习成绩 X%」或「实现自进化」**。
