## 五、已发现并**已纠正**的数据冲突（保留记录，防止回流）

| 冲突项 | 冲突双方 | 本套文档采信 | 位置 |

## 六、调研方法学上的已知局限（诚实声明）

1. **发表偏差**：自进化领域普遍「只报成功 seed」，论文数字可能不可复现。
2. **LLM 版本漂移**：API 模型一更新，历史分数就不可比——**必须冻结评估用的模型版本与量化档**（文档 06 §七）。
3. **二手转述比例**：本套文档中存在若干二手来源（已逐条标注 ⚠️），尤其是企业宣传数字（如某模型 tok/s、stars 数）。
4. **star 数会变**：文档 05 中的 star 量级来自报道或检索快照，**以 GitHub 实时为准**。
5. **调研环境限制**：个别域名（如 zenodo.org）在调研环境 DNS 不可解析，导致部分一手来源未能打开。
