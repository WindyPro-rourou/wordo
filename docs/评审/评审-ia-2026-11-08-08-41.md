# 评审（ia）2026-11-08-08-41

## auto/glm-5.3-flash

## 1) 三页签 + 底部导航够不够

**不够，缺的不是页签，是“进度感”入口。** 三个页签能容纳功能，但学生的核心动机是“今天还剩多少、我到哪了”，这需要一个常驻、零点击可见的进度位（如对话页顶部或底导航徽标：“还剩 5 题 / 3 个复习”），而不是埋在今日页里才知道。改法：页签数维持 3 个，但给“今日”tab 加角标数字；设置页拆出“学科切换”为对话页顶部的胶囊（手机端已有，桌面端补齐），否则换学科要点两三层。

## 2) 今日页块顺序

**基本对，但“复习队列→薄弱”缺一个“今日目标/预计耗时”的头块。** 学生打开今日页第一个问题不是“复习什么”而是“今天要做多久、从哪开始点”。改法：顶部加一个总览条（今日复习 N + 新题 M + 预计 X 分钟 + 一个“继续”主按钮，点击直接进入第一个待办）；user.md 和导出周报属于“回看”性质，折叠或移到底部“我的档案”区，避免稀释首屏行动性。复习队列在薄弱之前的顺序保留——SRS 到期是硬约束，薄弱是软建议。

## 3) 对话内出题/判分 vs 今日页开始复习，确实重复

**重复的根源是两处各自维护“下一道题是什么”的状态，且入口语义混淆。** 改法：收敛为“今日页是唯一排程入口，对话是唯一做题场”——今日页的复习/新题点击后跳转到对话流并注入对应题目（复用同一出题 pipeline），对话内只保留自然触发的轻量出题（学生主动说“考考我”），且这类题不计入 SRS 排程或计入但标注来源。否则 SRS 到期队列会被对话内随手机出的题打乱，间隔计算口径直接冲突。判分逻辑必须只有一条路径，对话内判分结果写同一账本、同一套蒙对不算掌握规则，这点你们的 schema 已保证，但排程入口必须唯一。

## 4) 学生最可能卡在哪

**第一卡点：首句学科判定错了怎么办。** 自动判定一旦错了，整段对话进错学科包，学生不知道能改、也不敢删对话重来。改法：判定后对话头部立即回显“已进入：数学 › 一元二次方程【改】”，一键换学科并迁移本轮上下文。

**第二卡点：蒙/说不准三档的选择心理负担。** 学生（尤其应试场景）倾向全选“确定”以显得好，导致置信度数据被污染、蒙对不算掌握失效。改法：把三档从“自我报告”改成“作答后追认”——先答题，判分后追问“这题你是真会还是蒙的”，配合连续几次“确定但错”自动降权其置信度申报，否则整个学习科学层建立在一个可被学生轻易绕过的自评上。

**第三卡点：ESP32/极简桥的断点续传心智。** 卡片集导出到设备、隔天作答回导入，学生不记得哪个对话对应哪批卡片。改法：导出时生成可读批次名+今日页给“待回收卡片集”一个回收入口，入库后标记完成。

## auto/deepseek-v4.1-flash

**1) 三页签是否够？架构对了，但缺一个“语境切换器”**  
够用，且足以构建强习惯。但“对话”和“今日”之间缺少“学科上下文”的持久联通——学生在对话里学完微积分，切到今日页，不知道复习队列来自哪儿。**改法**：不增加顶层页签，在所有页签顶部加一个全局“当前学科/课程”胶囊（点击可横滑切换）。对话页自动判定后，今日页的队列、薄弱区会立即随之刷新，把“多端”和“多学科”统一到同一个语境轨道上，而不是让用户在心里自己拼逻辑。

**2) 今日页块顺序：本质是“想起来”与“做起来”的顺序错了**  
当前队列→薄弱→计划→user.md→导出，是典型的“行动在前、仓促解释”，学生会把“薄弱”当成核心入口，挤出“计划”的地位。**改法**：顺序调整为 **计划（短文本，一句话今日目标）→ 复习队列（主操作，强制）→ 薄弱（诊断/详解）→ user.md（历史回溯）→ 导出（低频操作）**。“计划”必须是轻量的一句话引导（“今天攻克 5 道三角函数”），紧贴“复习队列”的上方，起到“启动器”作用，而不是被挤到第三层。

**3) 对话判分与今日复习重复：您做对了闭环，但UI上割裂了点击流**  
功能重叠本质是“叙事驱动”与“算法驱动”打架。对话是即时反馈，今日是批量调度，两者必须双向绑定。**改法**：收敛为**“卡片驱动”**。在今日页的“复习队列”每张卡片上放一个“深入对话”按钮，点击后以浮层方式在当前页打开mini对话窗，并高亮绑定该卡片；而对话主界面新增“加入今日队列”命令（像收藏/归档一样）。且明确规则：对话中触发的“判分”不会独立修改SRS周期，仅作为“临时结果”写入账本，**由今日页顶部“一键确认”按钮统一批量入账**。这既能避免在对话里频繁切换模块，又把决策权还给用户。

**4) 学生最可能卡死的步骤：首句自动判定后的“确认”缺失**  
对话页首句判定了学科，但没有“确认/纠正”的可视化反馈。学生说“用代数解不等式”，系统直接判定了，如果判定错误，学习科学全乱了，且他们根本无从察觉。**改法**：对话输入框右上角固定显示“当前学科”胶囊，判定完成时胶囊有 0.5 秒的荧光闪烁；点击胶囊可展开 3 个备选学科，选定后该对话的账本节点立即打上“人工修正”标签。这是最低成本的容错funnel，如果此处设计为“可跳过”，学习路径的根基就悬空。
